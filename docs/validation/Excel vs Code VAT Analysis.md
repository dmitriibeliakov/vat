## Key Findings

### 1. Box 3B ↔ 1E Shift (VAT Validity Reclassification)

The most significant difference is the systematic shift from Box 3B to Box 1E. This is **intentional and correct** - the code enforces VAT validity rules that the Excel process did not apply.

#### Reconciliation Table

| Quarter | Excel 3B       | Generated 3B   | Invalid VAT    | Gen + Invalid  | Residual |
|---------|----------------|----------------|----------------|----------------|----------|
| Q1      | -730,809.71    | -700,586.00    | -30,223.63     | -730,809.63    | -0.08    |
| Q2      | -769,170.73    | -703,855.00    | -65,289.74     | -769,144.74    | -25.99   |
| Q3      | -815,520.90    | -767,715.00    | -47,806.30     | -815,521.30    | +0.40    |

**Conclusion:** Excel 3B = Generated 3B + Invalid VAT Reclassified to 1E (within rounding)

The code correctly moves transactions from Box 3B to Box 1E when customers lack valid EU VAT numbers, per Dutch tax regulations.

---

### 2. Q1 Box 1A Discrepancy (Classification Difference)

**Issue:** Q1 shows a 136% difference in Box 1A (-8,293 Excel vs -19,580 Generated)

**Root Cause:** VAT code 95 "Ancill services NL" with Margin GL accounts (8205, 8206) classification difference:

| Item                                           | Excel Box | Generated Box | Amount      |
|------------------------------------------------|-----------|---------------|-------------|
| VAT 95 / GL 8205 (Commissions ancillary NL)    | 1E        | 1A            | -91.00      |
| VAT 95 / GL 8206 (Commission Hotels online)    | 1E        | 1A            | -11,195.79  |

**Explanation:**
- Excel manually classified these as 1E (0% export services)
- Generated script classifies Margin revenue with NL VAT code as 1A (21% domestic)
- This is a **business decision** about how to classify NL ancillary service commissions

**Impact:** ~11,287 EUR moved from 1E to 1A in generated reports

The following boxes match within 0.5% across all quarters:

## Recommendations

### 1. Accept VAT Validity Reclassification

The 3B → 1E reclassification is correct per Dutch tax law. The generated reports should be used for accurate ICP/VAT compliance.

### 2. Review VAT 95 Classification

Clarify the business rule for VAT code 95 (NL ancillary services) with Margin:
- Current code: Box 1A (21% domestic)
- Excel manual: Box 1E (0% services)

If 1E is correct, update `get_box()` logic in `main_old.py`.

### 3. Investigate Q2 5B Variances

Review GL 4074 and 4875 entries in Q2 to determine correct classification. May require manual review of source transactions.
